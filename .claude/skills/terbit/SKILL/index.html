/terbit

Timmy wrote the piece. Publish it as he wrote it. Run the steps in order. Run all commands from the timmy-say repo root unless a step says otherwise.

If the message is /terbit retry <url>, go to the Retry section.

Procedure

  1. Preflight.

    • Test each of ARTICLE_PAGE_ID, ARTICLE_PAGE_TOKEN, GH_TOKEN with [ -n "$VAR" ]. Never print a value.
    • If one is missing, stop. Tell Timmy which one. Tell him to start the session in the small-hours environment.
    • If ../instagram-autopost does not exist, clone it. Put the token in a header, never in the URL: git -c http.https://github.com/.extraheader="AUTHORIZATION: basic $(printf 'x-access-token:%s' "$GH_TOKEN" | base64 | tr -d '\n')" clone https://github.com/timmysay/instagram-autopost ../instagram-autopost
    • If python3 -c "import requests" fails, run pip install -r ../instagram-autopost/requirements.txt.

  2. Parse the message.

    • Remove the /terbit or Terbit: prefix.
    • Read the optional header lines at the top. Each header is on its own line: Tajuk: <title>, Jenis: artikel or Jenis: renungan.
    • Remove the header lines from the body.
    • Use renungan when no Jenis: line is present.
    • Use the Tajuk: value as the title when present.
    • If there is no Tajuk:, use the first line when it has 70 characters or fewer and no final full stop. Then remove that line from the body.
    • Otherwise, use the first sentence. Cut it to 70 characters at a word boundary. Keep the sentence in the body.
    • Tell Timmy the title you chose.

  3. Clean. Never edit.

    • Site text: remove only the _INVISIBLE, _ODD_SPACE and _CITATION patterns from ../instagram-autopost/scripts/common.py. Import them. Do not copy them.
    • Keep his Sumber: lines. Keep all other text exactly.
    • Facebook text: apply clean() from the same file to the original body.
    • Count the matches each pattern removed. Keep the counts for the report.
    • Do not fix spelling, wording, order or length.
    • Read the "Peraturan tetap" section of README.md. The /terbit message is Timmy's approval.
    • If the piece breaks a rule there, do not publish. Quote the rule and the sentence. Ask Timmy.

  4. Make the slug.

    • Run python3 scripts/slug.py "<title>".
    • If renungan/<slug>.md or articles/<slug>.md exists, append -2. Then try -3, and so on.

  5. Write the file.

    • Get the date with TZ=Asia/Kuala_Lumpur date +%Y-%m-%dT%H:%M:%S+08:00.
    • Set petikan to the first sentence of the body, 160 characters max.
    • Put title and petikan in double quotes if they contain : or # or start with a quote.
    • Split the body into paragraphs at blank lines. Separate paragraphs with one blank line.
    • renungan: write renungan/<slug>.md.
      • Frontmatter: title, date, petikan, jenis: renungan.
      • Wrap the first paragraph in <p class="drop">…</p>. Leave later paragraphs as plain text.
      • Match the shape of renungan/ambang-dan-udara.md exactly.
    • artikel: write articles/<slug>.md.
      • Frontmatter: title, date, petikan, jenis: tulisan, cover: /assets/covers/<slug>.png.
      • Wrap every paragraph in <p>…</p>. Make the first one <p class="drop">.
      • Make the cover with the scripts/cover/ pipeline:
        1. python3 scripts/cover/make-bg.py --slug <slug> --brief "<one concrete image from the piece>"
        2. python3 scripts/cover/strip-marks.py assets/covers/bg/<slug>.png
        3. CHROME=$(bash scripts/cover/ensure-chrome.sh)
        4. node scripts/cover/make-cover.mjs --theme wartawan --slug <slug> --chrome "$CHROME" --bg "assets/covers/bg/<slug>.png" --kicker "TULISAN|<TOPIK>" --l1 "<title part 1>" --l2 "<title part 2>" --stand "<his first sentence>" --byline "Timmy Say" --date "<10 OKTOBER 2026>" --motif none
      • Keep --l1 and --l2 under about 22 characters each. Use his words only.
      • If any cover step fails, remove the cover: line. Publish anyway. Say so in the report.
      • SynthID can stay in the pixels after the strip. Say so in the report.

  6. Lint.

    • Run scripts/lint-artikel.sh <file>.
    • If it finds a hit, show the lines. Stop.

  7. Commit and push.

    • git add the file and the cover files if made.
    • Commit with the message terbit: <slug> and the line Co-Authored-By: Claude <noreply@anthropic.com>.
    • Run git push origin main.

  8. Wait for the page.

    • renungan URL: https://timmysay.github.io/renungan/<slug>/
    • artikel URL: https://timmysay.github.io/artikel/<slug>/. Artikel pages live under /artikel/, not /articles/.
    • Poll with curl -s -o /dev/null -w '%{http_code}' <url> every 20 seconds. Stop at 200. Stop after 8 minutes.
    • If you get no 200, run gh workflow run pages.yml one time. Wait 8 more minutes the same way.
    • If you still get no 200, report the failure. Do not post to Facebook.
    • When you get 200, run scripts/indexnow-ping.sh <url>.

  9. Post to Facebook.

    • Search ../instagram-autopost/data/articles.jsonl for the URL. If the URL is there, stop. One post per piece, ever.
    • Build the message: title, a blank line, the full Facebook-cleaned body, a blank line, Baca di laman: <url>.
    • Write the message to a temp file.
    • In ../instagram-autopost, run python3 scripts/post_text.py "<url>" < <temp file>.
    • Keep the post id it prints.

  10. Record.

    • Append one line to ../instagram-autopost/data/articles.jsonl: {"date": "<YYYY-MM-DD>", "title": "<title>", "url": "<url>", "post_id": "<id>"}
    • In ../instagram-autopost, set the git identity if it is not set.
    • Run git add data/articles.jsonl && git commit -m "article <date>" && git push origin HEAD:master.
    • This line stops the 08:00 morning routine from posting the same piece again.

  11. Report in chat, five lines or fewer:

    • site URL
    • Facebook post id
    • title and slug
    • what the clean step removed, as counts
    • cover status, for artikel only

Retry

Use this when the message is /terbit retry <url>.

  1. Run step 0.
  2. Get the slug from the URL. Read the file for that slug in renungan/ or articles/.
  3. Use its title. Use its body with the <p> tags removed as the body.
  4. Check that the URL returns 200.
  5. Go to step 8.

Hard rules

  • Never rewrite his words.
  • One Facebook post per piece. The ledger data/articles.jsonl is the source of truth.
  • Never post to the Instagram account. Never post to The Small Hours page.
  • Never print a token value.
  • If a step after the push fails, name that step exactly. Tell Timmy the page is live. Tell him to retry the Facebook step with /terbit retry <url>.
